## 1. Classification method

The ECC final report does not assign explicit Finding IDs or severity labels. The IDs `PF-01` to `PF-27` below are assigned during this post-ECC analysis and are stable references for the remaining work.

Severity rules used here:

- **Critical**: blocks core runtime, end-to-end chat, model/knowledge execution, or security assurance.
- **High**: affects SOP availability, retrieval correctness, citation validity, release evidence, or overall regression health.
- **Medium**: affects maintainability, tooling confidence, test stability, or secondary verification.
- **Low**: already verified PASS, administrative, or non-blocking.

Allowed statuses from the contract are used exactly: `OPEN`, `RESOLVED`, `PARTIAL`, `FALSE_POSITIVE`, `UNVERIFIED`.
